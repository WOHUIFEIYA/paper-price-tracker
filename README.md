# 浙江废纸价格追踪

免费静态报价页，抓取生意社废纸报价中浙江绍兴华宇、浙江嘉兴景兴、浙江嘉兴山鹰的黄板纸 A 级终端价，展示三家各自最新价及其算术平均价，并保留已抓到的历史记录。

## 免费发布成网址

1. 将本文件夹内容上传到一个新的 GitHub 仓库，仓库名称可用 `paper-price-tracker`。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 打开 **Actions** 并运行一次 **Update prices and publish**。发布后，GitHub Pages 会给出 `https://<用户名>.github.io/<仓库名>/` 免费网址。
4. 自动任务按 UTC 02:30、08:30 执行，也就是北京时间每天 10:30、16:30。Actions 运行记录可查看每次采集状态。

## 本地预览

在此文件夹启动任意静态 HTTP 服务并打开 `index.html`。首次页面数据来自来源页面当时公开的记录；成功发布后，定时任务会自动刷新并累积历史数据。

## 数据说明

来源页面：<https://fz.100ppi.com/price/>。页面发布日期代表来源网站给出的报价日期，定时采集时间代表机器人访问时间，两者可能不同。若来源页面改版或拒绝自动访问，采集会在 Actions 中报错，页面保留上次成功更新的数据。
